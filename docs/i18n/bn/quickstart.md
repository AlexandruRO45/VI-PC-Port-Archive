## Leonida কী?

Leonida হলো Grand Theft Auto VI (Xbox Series সংস্করণ)-এর একটি স্ট্যাটিক রিকম্পাইলেশন (Static Recompilation) প্রজেক্ট,
যার লক্ষ্য গেমটিকে উইন্ডোজে নেটিভলি চালানো। এটি সম্পূর্ণভাবে **আপনার নিজস্ব পিসিতে, আপনার নিজের গেম প্যাকেজ থেকে** বিল্ড
করা হয়। কনসোলের RDNA2 শেডারগুলোকে Vulkan SPIR-V-তে রূপান্তর করা হয়, আপনার প্যাকেজ থেকে মডেল ও টেক্সচার পড়া হয় এবং
কনসোলের সিস্টেম সফটওয়্যারকে উইন্ডোজ শিমস (Shims) হিসেবে পুনঃবাস্তবায়ন করা হয়।

> [!IMPORTANT]
> এই রিপোজিটরিতে **গেমের কোনো ফাইল, লাইসেন্স কী বা এক্সিকিউটেবল নেই**, এবং এগুলো কীভাবে সংগ্রহ করতে হয় তাও বলা হয় না।
> এখানে কোনো ধরনের কপিরাইট প্রোটেকশন বা এনক্রিপশন বাইপাস করা হয় না। বিল্ড প্রক্রিয়ায় যা কিছু তৈরি হয় (অনূদিত শেডার,
> এক্সট্র্যাক্ট করা ফাইল, ওয়ার্ক ফোল্ডার, সেভ ডাটা) তা আপনার কপি থেকে তৈরি হয় এবং **আপনার পিসিতেই সুরক্ষিত থাকতে হবে**:
> কখনোই এই ফাইলগুলো গিটহাবের ইস্যু বা পুল রিকোয়েস্টে শেয়ার করবেন না (বিস্তারিত: [`CONTRIBUTING.md`](../../../CONTRIBUTING.md))।

প্রজেক্টটি এখনো প্রাথমিক পর্যায়ে রয়েছে: **গেমটি এখনো সরাসরি চালু বা বুট হয় না**।

## সমর্থিত প্ল্যাটফর্ম

বর্তমানে কোনো প্ল্যাটফর্মেই গেমটি সম্পূর্ণ খেলার উপযোগী নয়। তবে যেসব টুলস ও রানটাইম কাজ করে:

- **Windows**: সবকিছু (`make_game.py`, টুলস এবং D3D12 → Vulkan লেয়ার সহ `gta6rt` রানটাইম ও টেস্ট)।
- **Linux**: শেডার অনুবাদক, এসেট টুলস এবং Vulkan GPU টেস্টগুলো নেটিভলি চলে (RADV ও NVIDIA ড্রাইভার উভয়তেই পরীক্ষিত)। রানটাইম
  উইন্ডোজ কোড হওয়ায় এটি clang-cl এবং xwin দিয়ে ক্রস-বিল্ড হয় এবং Wine বা Proton-এর অধীনে টেস্ট চলে।
- **macOS (Apple Silicon)**: পাইথন টুলস এবং ভলকান টেস্টগুলো MoltenVK (Homebrew) অথবা KosmicKrisp-এর মাধ্যমে নেটিভলি চলে।
- **AMD RDNA1 ও RDNA2 (RX 5000 / 6000 / 7000)**: কনসোলের নিজস্ব RDNA2 আর্কিটেকচারের সাথে সরাসরি মিল থাকায় এর ৬৪-ওয়াইড
  সাবগ্রুপে wave64 শেডারগুলো নেটিভলি এক্সিকিউট হয়।

বিভিন্ন প্ল্যাটফর্মের জিপিইউ টেস্টের ফলাফল দেখতে [Issue #166](https://github.com/ItsNotRexed/Leonida/issues/166) দেখুন।

## প্রয়োজনীয় রিকোয়ারমেন্টস (Prerequisites)

- **আপনার নিজস্ব গেম কপি**: Xbox Series প্যাকেজ, সংস্করণ `1.0.2.1` (যে ফোল্ডারে `MicrosoftGame.Config` এবং `.rpf` ফাইলগুলো
  সরাসরি রিড করা যায়)।
- **Windows 10/11 x64**: সম্পূর্ণ বিল্ডের জন্য ড্রাইভে প্রায় **৩৫০ জিবি ফাঁকা জায়গা** প্রয়োজন (যা `--work` দিয়ে অন্য ড্রাইভেও রাখা যায়)।
- [Python 3.12+](https://www.python.org/downloads/) (ইনস্টলেশনের সময় অবশ্যই "Add python.exe to PATH" টিক দিন)।
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)।
- [Vulkan SDK](https://vulkan.lunarg.com/) (`spirv-as`, `spirv-val` এবং `vulkaninfo`)।
- [LLVM 21+](https://github.com/llvm/llvm-project/releases) (AMDGPU টার্গেট সহ `llvm-mc`):
  - উইন্ডোজের অফিশিয়াল LLVM ইনস্টলারে সাধারণত AMDGPU টার্গেট থাকে না। রিপোজিটরির রুট থেকে PowerShell-এ `.\scripts\build_llvm_mc.ps1`
    চালালে এটি স্বয়ংক্রিয়ভাবে প্রয়োজনীয় `llvm-mc.exe` বিল্ড করে নেয় (এর জন্য Visual Studio C++ বিল্ড টুলস প্রয়োজন)।
  - [conda](https://docs.conda.io/) ব্যবহারকারীদের জন্য: `conda install -c conda-forge llvm-tools` দিয়ে ইনস্টল করে `LLVM_MC` এনভায়রনমেন্ট
    ভেরিয়েবলে পাথ সেট করে দিতে পারেন।
- **Visual Studio 2022**: *Desktop development with C++* এবং **Windows SDK `10.0.26100` বা তার নতুন সংস্করণ** সহ ইনস্টল থাকতে হবে
  (রানটাইম বিল্ডের জন্য Root Signatures 1.2 প্রয়োজন)।
- [ffmpeg](https://ffmpeg.org/download.html) PATH-এ যুক্ত থাকা ভালো *(ঐচ্ছিক: XMA2 অডিও ডিকোড করার জন্য)*।

## কীভাবে বিল্ড করবেন

### সহজ পদ্ধতি (Windows)

১. উপরের রিকোয়ারমেন্টগুলো ইনস্টল করুন।
২. সাবমডিউল সহ রিপোজিটরিটি ক্লোন করুন:
   ```powershell
   git clone --recursive https://github.com/ItsNotRexed/Leonida
   ```
   *(GitHub থেকে সরাসরি ZIP ডাউনলোড করলে `third_party/rpf9-explorer` সাবমডিউলটি থাকে না, তাই গিট ক্লোন ব্যবহার করা বাঞ্ছনীয়)*।
৩. **`Build.bat`** ফাইলে ডাবল-ক্লিক করুন।

স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে আপনার পিসির বিভিন্ন ড্রাইভ স্ক্যান করে গেমের ফোল্ডার খুঁজে বের করবে। যদি একাধিক কপি পায় তবে পছন্দ করতে বলবে, আর
না পেলে ফোল্ডারের পাথ পেস্ট করতে বলবে। বিল্ডের ফলাফল ডিফল্টভাবে `Documents\Leonida` ফোল্ডারে জমা হয়।

### টার্মিনাল বা কমান্ড লাইন থেকে (`make_game.py`)

```powershell
python -I make_game.py --find                          # পিসিতে থাকা গেম কপি তালিকাভুক্ত করে
python -I make_game.py --pick                          # ফোল্ডার ব্রাউজ করে গেম দেখানোর উইন্ডো খোলে
python -I make_game.py --check                         # গেমের কপি ভেরিফাই করে, কিন্তু বিল্ড করে না
python -I make_game.py --check --full-check            # প্রতিটি ফাইলের SHA-256 হ্যাশ পুঙ্খানুপুঙ্খ মেলায়
python -I make_game.py --game "D:\Games\GTA6" --out "D:\Games\Leonida" --work "E:\work"
python -I make_game.py --stages shaders,assets         # কেবল নির্দিষ্ট ধাপগুলো চালায়
python -I make_game.py --wave64-emulate off            # auto (ডিফল্ট), on বা off
```

বিল্ডের ধাপগুলো এই ক্রমানুসারে চলে: `check` → `shaders` → `assets` → `runtime` → `pipelines`। 
`pipelines` ধাপটি আপনার জিপিইউ ড্রাইভার ব্যবহার করে প্রতিটি কনভার্ট করা শেডার কম্পাইল করে পরীক্ষা করে এবং একটি পাইপলাইন ক্যাশ তৈরি করে।

- **`--wave64-emulate`**: NVIDIA এবং Intel জিপিইউতে ৩২-ওয়াইড সাবগ্রুপ থাকায় wave64 শেডারগুলো নিখুঁতভাবে চালানোর জন্য এই অপশন প্রয়োজন।
  AMD RDNA1 ও RDNA2 জিপিইউতে ডিফল্টভাবে নেটিভ wave64 চলে।
- **ফলব্যাক অপশন**: আপনার ডিভাইসে নির্দিষ্ট কোনো ভলকান ফিচার অনুপস্থিত থাকলে `--no-float-controls`, `--bary-fallback`,
  `--texel-offset-fallback` বা `--mesh-compute` ব্যবহার করা যায় (বিস্তারিত: [`docs/design.md`](../../design.md))।
- **`--work`**: বিল্ডের জন্য অন্তর্বর্তীকালীন ফাইল রাখার জন্য পর্যাপ্ত ফাঁকা জায়গা বিশিষ্ট ড্রাইভ নির্বাচন করুন।

## সাধারণ সমস্যা ও সমাধান

- **GitHub থেকে Download ZIP করার পর বিল্ড এরর**: ZIP ফাইলে `third_party/rpf9-explorer` থাকে না। রিপোজিটরির ভেতরে গিয়ে
  `git submodule update --init` চালান।
- **শেডার ট্রান্সলেশনে llvm-mc এরর**: নিশ্চিত করুন `LLVM_MC` পাথটি ঠিকভাবে ডিফাইন করা আছে এবং ইনস্টল করা LLVM বিল্ডে AMDGPU টার্গেট অন্তর্ভুক্ত রয়েছে।
- **SDK রুট সিগনেচার এরর**: নিশ্চিত করুন উইন্ডোজ SDK ভার্সন `10.0.26100` বা তার চেয়ে নতুন সংস্করণ ইনস্টল করা আছে।
