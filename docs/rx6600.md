# AMD Radeon RX 6600 Vulkan test notes

Recorded runs of standalone Vulkan test programs on one machine. These were direct runs of executables from the
`runtime-windows` CI artifact (the Runtime workflow's artifact of the commit that built it; that commit was not
recorded), not a `run_gpu_tests.py` suite pass, so there are no pass/fail counts.

- **GPU:** AMD Radeon RX 6600 (Vulkan device name `AMD Radeon RX 6600`, deviceID `0x73ff`, discrete, Vulkan API
  1.4.315). An AMD Radeon(TM) Graphics iGPU is also present; the test programs' device pick prefers discrete.
- **OS:** Windows 10 22H2 (build 19045).
- **Driver:** AMD Adrenalin `25.10.30.02` (Vulkan driverVersion `2.0.353`, Windows driver `32.0.21030.2001`).

| Program | Shader / cases | Result |
|---|---|---|
| `vk_store_test.exe` | `runtime-windows\generated\cs_user_data.spv`, `words` mode | exit 0; the image word lines were all zero. `cs_user_data.spv` performs no image stores, so this exercised device and pipeline creation and the dispatch rather than store results |
| `vk_xdxr_build_test.exe` | the BLAS cases (one/five/random/grid/transform/two-geometry/empty, in-place and into-other-buffer refits) and the four-instance TLAS | ran on the device |

Heavy, sustained Vulkan test runs can reset the AMD Adrenalin driver — observed here as a black screen
followed by a driver reset during earlier runs — so run the tests one at a time. Suite-level results for this
GPU belong in [#166](https://github.com/ItsNotRexed/Leonida/issues/166) as usual; setup and known problems are
in [testing.md](testing.md).
