# Reporting a security issue

For a suspected vulnerability in Xbox2Windows code, build scripts or a published GPU-check package, contact the maintainer privately using the public email on the [repository owner's GitHub profile](https://github.com/R0Y00). Include the commit or release tag, affected component, observed impact and the smallest source-built example or reproduction steps you can share.

Keep sensitive details in that private exchange while the report is assessed. Ordinary build failures, graphics mismatches and unsupported hardware capabilities belong in the [public issue tracker](https://github.com/R0Y00/Xbox2Windows/issues/new/choose).
