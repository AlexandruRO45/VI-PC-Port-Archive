Motor de Validação Integrado

Valide o ambiente, o código-fonte e a integridade da sua cópia antes de iniciar um build longo.

Pré-requisitos do Sistema

Verifica Python 3.12+, .NET 8 SDK, Vulkan SDK (spirv-as/spirv-val), LLVM llvm-mc com target AMDGPU, Visual Studio C++, FFmpeg e espaço livre em disco.

Integridade do Pacote (SHA-256)

Compara nomes, tamanhos e hashes SHA-256 contra game/xbox-1.0.2.1.json em paralelo, relatando arquivos ausentes ou corrompidos.

Validação de Código & CI

tools/validate.py e a suíte de testes unitários verificam sintaxe Python, esquemas de manifesto e garantem zero dados do jogo no repositório.

python -I tools/validate.py env && python -I tools/validate.py code

Pipeline Completo

Cada estágio salva marcadores de progresso: se o build parar, ele continua exatamente de onde parou.
